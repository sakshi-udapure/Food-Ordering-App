# 🍔 Food Ordering Web App

A simple food ordering website built using Flask.

---

## 🚀 Features
- Food menu display
- Add to cart system
- Remove from cart
- Total bill calculation
- Food suggestion system

---

## 🛠️ Tech Used
- Python
- Flask
- HTML

---

## ▶️ How to Run
1. pip install flask
2. python app.py
3. Open http://127.0.0.1:5000/
